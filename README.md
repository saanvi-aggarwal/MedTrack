# MedTrack – Medicine Expiry & Stock Monitoring System

A Java-based desktop application for managing medicine inventory, monitoring expiry dates, and tracking stock transactions efficiently.

### Features
- Medicine and batch management
- FEFO-based stock allocation (First Expiry, First Out)
- Purchase and sale transaction tracking
- Medicine expiry monitoring
- Low-stock alerts
- Database transaction handling and input validation

### Tech Stack
`Java` · `Java Swing` · `MariaDB` · `JDBC` · `Maven`

### Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/saanvi-aggarwal/MedTrack.git
   ```
2. Import the project into Eclipse as an existing Maven project.
3. Create the `medtrack` database in MariaDB and initialize the required tables.
4. Configure database credentials using environment variables:
   `MEDTRACK_DB_URL`, `MEDTRACK_DB_USER`, `MEDTRACK_DB_PASSWORD`.
5. Run `Main.java`.
